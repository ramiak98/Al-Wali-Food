# Al Wali Food website (demo)

Showcase website for Al Wali Food, built with Astro and Tailwind CSS. No e-commerce:
visitors find a store or contact the team. The plan, copy and legal drafts are in
[docs/](docs/README.md).

This is a **demo**: products, company details, sample stores and events are placeholders.

## Run it locally

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static site in dist/
```

## Photos

`src/data/photos.ts` lists every site photo. Each one is a free photo from
[Unsplash](https://unsplash.com/license) (free for commercial use, no attribution
required), loaded from Unsplash's image CDN. Each also has a drawn stand-in in
`public/images/` (generated by `npm run images`), shown if the photo cannot load or
when the site is built with `PUBLIC_PHOTOS=off`. Replace them with Al Wali Food's own
or licensed photos before launch.

Product packshots in `public/images/products/` are drawn placeholders until real
product photos arrive.

## Publish

- **Vercel (recommended):** import this repository at vercel.com/new. Vercel detects
  Astro, and every push deploys automatically. This version shows the Unsplash photos.
- **Claude preview:** `PUBLIC_PHOTOS=off npm run build && node scripts/make-preview.mjs`
  writes a flat copy with relative links to `preview-build/`, used for the Claude
  Artifact preview (which cannot load outside images).
